# Техническое задание: Локальное приложение анонимизации табличных данных

## 1. Общее описание проекта

### 1.1 Назначение
Приложение для безопасной работы с персональными данными в табличном формате. Заменяет персональные данные (ФИО, телефоны, email, адреса и др.) на целочисленные индексы, позволяет работать с анонимизированной таблицей и восстанавливать исходные данные по запросу.

### 1.2 Ключевые ограничения (hard requirements)
| Требование | Описание |
|---|---|
| **Офлайн** | Приложение НЕ подключается к интернету. Все зависимости — локальные пакеты Python. |
| **Без нейросетей** | Обработка данных — только детерминированные алгоритмы (словари, хеши, маппинги). |
| **Локальность** | Вся файловая система — локальный компьютер. Никаких облачных вызовов. |
| **Обратимость** | 100% восстановление исходных данных из анонимизированной таблицы + маппинга. |
| **Целостность** | Одно и то же персональное значение всегда получает один и тот же индекс (внутри сессии). |

## 2. Архитектура

### 2.1 Стек технологий
- **Язык:** Python 3.10+
- **CLI-интерфейс:** `argparse` / `rich` (опционально, для красивого вывода)
- **Работа с таблицами:** `pandas` + `openpyxl` (для Excel) / `xlrd` (для .xls)
- **Хранение маппинга:** JSON-файл (или зашифрованный JSON)

## 3. Спецификация данных

### 3.1 Входные форматы
- `.xlsx` / `.xls` — файлы Excel
- `.csv` — файлы с разделителями

### 3.2 Типы персональных данных (каталог)
| Тип поля | Примеры колонок | Стратегия замены |
|---|---|---|
| **Имя / ФИО** | `ФИО`, `Имя`, `Фамилия`, `Отчество` | Словарь: значение → индекс |
| **Телефон** | `Телефон`, `Phone`, `Моб. телефон` | Словарь: значение → индекс |
| **Email** | `Email`, `E-mail`, `Почта` | Словарь: значение → индекс |
| **Паспорт** | `Паспорт`, `Серия`, `Номер паспорта` | Словарь: значение → индекс |
| **ИНН** | `ИНН` | Словарь: значение → индекс |
| **Адрес** | `Адрес`, `Прописка` | Словарь: значение → индекс |
| **Дата рождения** | `Дата рождения`, `ДР`, `DOB` | Словарь: значение → индекс |
| **Любой текстовый столбец** | По решению пользователя | Словарь: значение → индекс |

### 3.3 Маппинг (словарь замен)
```json
{
  "version": 1,
  "created_at": "2026-08-25T10:00:00",
  "columns": {
    "ФИО": {
      "type": "name",
      "mapping": {
        "Иванов Иван Иванович": 1,
        "Петрова Мария Сергеевна": 2,
        "Сидоров Алексей Петрович": 3
      },
      "reverse": {
        "1": "Иванов Иван Иванович",
        "2": "Петрова Мария Сергеевна",
        "3": "Сидоров Алексей Петрович"
      }
    },
    "Телефон": {
      "type": "phone",
      "mapping": {
        "+79001234567": 1,
        "+79009876543": 2
      },
      "reverse": {
        "1": "+79001234567",
        "2": "+79009876543"
      }
    }
  }
}
```

## 4. Спецификация функционала

### 4.1 Команды CLI

```bash
# Анонимизация таблицы
python main.py anonymize --input data.xlsx --output anon_data.xlsx --mapping mapping.json

# Деанонимизация (возврат исходных данных)
python main.py deanonymize --input anon_data.xlsx --mapping mapping.json --output restored.xlsx

# Просмотр маппинга (безопасно — показывает только статистику)
python main.py info --mapping mapping.json

# Шифрование маппинга
python main.py encrypt-mapping --mapping mapping.json --password mypass --output mapping.enc

# Расшифрование маппинга
python main.py decrypt-mapping --mapping mapping.enc --password mypass --output mapping.json
```

### 4.2 Алгоритм анонимизации

```
ВХОД: Excel/CSV файл, маппинг (опционально — для до-анимонизации)

1. ЧТЕНИЕ ФАЙЛА
   → Загрузить таблицу в pandas DataFrame
   → Определить типы колонок (auto-детекция или ручной выбор)

2. АВТООПРЕДЕЛЕНИЕ ПЕРСОНАЛЬНЫХ КОЛОНОК (column_detector.py)
   → Проверить имя колонки по списку паттернов (config.py)
   → Проверить содержимое колонки (номера телефонов, email-паттерны и т.д.)
   → Предложить пользователю список колонок для анонимизации

3. СОЗДАНИЕ / ЗАГРУЗКА МАППИНГА
   → Если маппинг новый: для каждого уникального значения → сгенерировать индекс
   → Если маппинг существующий: загрузить и дополнить новыми значениями
   → Индекс = следующее целое число (1, 2, 3, ...)

4. ЗАМЕНА ДАННЫХ
   → Для каждой целевой колонки:
     df[col] = df[col].map(mapping[col]["mapping"])
   → Незнакомые значения пропускаются (NaN) или логируются как предупреждение

5. СОХРАНЕНИЕ
   → Записать анонимизированную таблицу в файл
   → Записать маппинг в JSON (или зашифрованный .enc)
   → Вывести статистику: кол-во заменённых значений по колонкам
```

### 4.3 Алгоритм деанонимизации

```
ВХОД: Анонимизированная таблица + маппинг

1. ЧТЕНИЕ
   → Загрузить анонимизированную таблицу
   → Загрузить маппинг

2. РЕВЕРС-ЗАМЕНА
   → Для каждой колонки в маппинге:
     df[col] = df[col].astype(str).map(mapping[col]["reverse"])
   → Значения, не найденные в reverse → оставить как есть + логировать

3. СОХРАНЕНИЕ
   → Записать восстановленную таблицу
   → Вывести статистику восстановления
```

### 4.4 Определение колонок (авто-детекция)

`column_detector.py` проверяет:
- **По имени колонки:** паттерны из `config.py` (список known-полей)
- **По содержимому:**
  - Телефон: regex `^\+?\d{10,15}$`
  - Email: regex `^[\w\.-]+@[\w\.-]+\.\w+$`
  - ИНН: 10 или 12 цифр
  - Паспорт: regex `^\d{4}\s?\d{6}$`
- **По типу данных:** object/str колонки — кандидаты на анонимизацию

### 4.5 Шифрование маппинга (опционально)

- Алгоритм: Fernet (AES-128-CBC + HMAC, из библиотеки `cryptography`)
- Ключ: PBKDF2 из пароля пользователя (100 000 итераций, salt)
- Формат файла: `{"salt": "...", "data": "..."}` в JSON
- Без пароля маппинг не расшифровывается

## 6. Безопасность

### 6.1 Принципы
1. **Нет сетевого взаимодействия** — ни одного HTTP/HTTPS-запроса
2. **Нет сторонних зависимостей для обработки данных** — только pandas, openpyxl, cryptography
3. **Маппинг = ключ** — без маппинга восстановить данные невозможно
4. **Шифрование маппинга** — рекомендуется хранить зашифрованным
5. **Не пишем персональные данные в логи** — только статистика (кол-во строк, кол-во уникальных)

### 6.2 Проверка на сетевые вызовы
В процессе разработки — pytest-тест, который патчит `socket.connect` и убеждается, что ни один модуль не делает сетевых вызовов.

| `test_column_detection` | Автоопределение персональных колонок |
| `test_csv_roundtrip` | То же, что roundtrip, но для CSV |
| `test_encrypted_mapping` | Шифрование → расшифрование маппинга |
| `test_no_network_calls` | Проверка отсутствия сетевых вызовов |
